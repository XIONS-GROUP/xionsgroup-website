# Archive

This directory preserves superseded implementation work and is excluded from the Astro route tree.

- `pages/` — previous homepage alternatives
- `components/`, `layouts/`, `styles/` — currently unused interface code
- `legacy-site/` — former duplicate Astro project

Do not develop or run deployment commands from this directory. Restore a file to `src/` only after checking its imports and running `npm run build`.
