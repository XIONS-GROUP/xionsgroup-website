# 2026-09-22 · 退场改为开场倒放，整圈无缝循环

承接[同日流光循环记录](2026-09-22-flow-loop.md)。本条**替代**[时间线](2026-09-12-to-22.md)第 9 条中“光沿四臂扩展回白场”的退场方案。

## 用户需求

用户确认认可上一轮出现的开场反色观感（“我觉得你刚开始加的这个反色的这个动画特别好”），并要求：“最后的这个 X 到白场，可以替换成和开头的动画一样的，但是是反过来的。这样它这样的话就是首尾有一个衔接嘛。整个动画的话，现循环的这种感觉。”同时给出工具箱截图的新参数。

## 参数：旧值 → 新值

| 项目 | 旧值 | 新值 |
| --- | --- | --- |
| 白场停留 | 0s | **2s** |
| 白场 → X | 10s | 10s（未改） |
| 旋转前停留 | 2s | 2s（未改） |
| 旋转 180° | 4s | 4s（未改） |
| 旋转后停留 | 2s | 2s（未改） |
| X → 白场 | 5s | 5s（未改），但**换了做法** |
| 合计 | 23s | **25s** |
| 流光速度 | 1.00× | **0.55×** |
| 流光强度 | 290% | 290%（未改） |

X 高度 390/650px、2876:1580 比例、噪点 12%/0.9px、流光周期 8s/5s、旋转角度与缓动曲线未改。

## 实施结果

- [src/config/hero-light.ts](../../src/config/hero-light.ts)
  - 新增装配进度 `assembly`：形成阶段 0→1，停留与旋转保持 1，退场 1→0，统一驱动 `formation` uniform。`motionEase` 是关于中点对称的五次 S 曲线，1−E(u) 与 E(1−u) 等价，所以退场就是形成的严格时间倒放。
  - 删除原来单独的 `exit` 返回值。
  - 旋转角改为跨轮累加：`angle = π × (turns + ease)`，`turns = floor(elapsed/total) % 2`。
- [src/scripts/hero-light.ts](../../src/scripts/hero-light.ts)：删除 `returning` uniform、`exitLocation` 及沿四臂扩散的 `dissolve` 代码块；噪点淡出改由 `cycle` 直接控制（`texture = smoothstep(2.,8.,cycle)`），退场时随 `cycle` 回落自然消失。
- [src/pages/\[preview\].astro](../../src/pages/[preview].astro)：时长说明补充“X → 白场是「白场 → X」的倒放，所以一轮的末帧与首帧相同，循环无缝”。

### 为什么要动旋转角

用户只提了退场，但只改退场达不到“衔接”的目标。原来每轮结束旋转角从 180° 跳回 0°。X 轮廓本身 180° 对称，单看剪影发现不了；但流光是在旋转后的坐标系里算的，角度归零会让光斑在接缝处瞬间镜像跳位，强度 290% 下非常明显。改成累加后接缝两侧角度相同；取模 2 使它每两轮回到 0°，数值不会无限增长。每轮仍然只转 180°，时长和角度都没变。
