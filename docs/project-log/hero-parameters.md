# 首页 Hero：参数与需求演变

最后确认：2026-09-22 第二轮，用户工具箱截图（流光 290% / 1.00×，时长 0/10/2/4/2/5）并明确“流光不停循环，不分阶段”。更早一轮为同日“手机 X 高度 390px”截图 `Screenshot 2026-09-22 at 12.27.07.png`。截图的临时系统路径不作为长期依赖，数值完整转录如下。

## 每轮演变

| 顺序 | 用户需求与决定 | 实施/依据 |
| --- | --- | --- |
| 1 | 从摄影/轮播方案转向黑白、波浪曲线的程序动效，黑色占多数 | 创意探索；未把参考网页直接复制成成品 |
| 2 | 图片 1 的 X 构图 + 图片 2 的细腻明暗；考虑 Photoshop、Blender、代码 | 选择程序化 WebGL；无需 Blender 渲染或视频下载，`235ffa9` |
| 3 | 中心锁定；比例、造型和虚实参照参考；噪点强度/粗细可调 | `cc062f0`；分析式重建，不能声称与原图逐像素相同 |
| 4 | 窗口和设备变化不能拉伸；缩小窗口只裁切，不不断缩小 X | 按高度计算、保持 2876:1580，`6d2ad5f` |
| 5 | 用户本地调整的噪点应用为默认；希望有动态 | 默认 12%、0.9px；早期克制光线变化，`6d2ad5f` |
| 6 | 播放按钮只保留图标；本地可隐藏工具箱、手机/桌面预览、随可见区域给选项 | `5429a70`；390×844 / 1440×900 模拟视窗，不等于 X 高度 |
| 7 | 手机 X 定为 360px；先提两个动态方案，不立即改；随后选第一个白场聚合方案 | `a8f3d95`；整个 Hero 参与动画，包含 X 上下留白 |
| 8 | 完整 X 太静止；希望桌面高度和每段时长可调，先出方案 | 需求进入下一轮工具箱与旋转实现 |
| 9 | 保留形成；完整 X 中心旋转 180°，先慢后快；光沿四臂扩展回白场 | `406e803`；时长暂定 2/8/4/6/3/5，共 28s |
| 10 | 工具箱容纳更多参数；先确认时长再抛光细节 | 380px 分组侧板、可收起、时间轴拖动、暂停/重播；参数存浏览器 |
| 11 | 当前确认：手机390、桌面650，截图时长0/5/0/4/1/5 | 本轮落实到源码和实际组件，合计15s；同步记录与交接 |
| 12 | 整理中追加：宽柔光+更快细高光，持续跨旋转前/旋转/旋转后，转换期不使用 | 共用形成结束后的时钟，阶段间不重置；0.45s柔和进入/离开均在完整X阶段内完成 |
| 13 | **本轮：流光“不停地在循环”，不按阶段开始，只调速度；时长按截图 0/10/2/4/2/5，强度290%** | 取消阶段门控、淡入和退场刹车，流光改用独立自由时钟；**替代第12条的三阶段方案** |

流光不改变X轮廓、比例、居中和噪点。宽柔光在内部大面积明暗间移动（相对原光场−28%至+4%）；细高光沿另一侧弧边移动（峰值幅度0.22），周期更短。

第13轮起，流光不再分阶段：`flowTime` 直接取未取模的累计播放时间，`flowAmount` 恒为 1，因此形成、停留、旋转、退场全程都在流光，动画循环回到 t=0 时流光相位也不跳变。退场阶段流光仍在计算，只是被扩散白场逐步覆盖。暂停会冻结同一时钟，减弱动态模式仍然关闭流光（强度置 0）。

**已知视觉后果，待用户确认：** 强度 290% 且全程常开后，t=0 的全白开场不再是纯白——X 轮廓会以灰色柔影提前显影，整个 10 秒形成过程都叠着流光。这是“流光一直循环”的直接结果，非缺陷；如果希望开场恢复纯白，需要用户另行决定是否给形成阶段单独设一条淡入。

## 本地预览设置迁移

旧 `xions-preview-layout-v2` 和 `xions-preview-timing-v1` 会覆盖默认值，所以本次升级为 `xions-preview-layout-v3` / `xions-preview-timing-v2`。首次使用新版本时采用新 X 高度和新时长，只迁移原来的手机首屏最低高度；已有 `xions-hero-grain-v2` 噪点偏好继续保留。旧存储不删除，后续预览调整仍保存在当前浏览器。

第13轮未再升级存储键：`xions-preview-timing-v2` 和 `xions-preview-flow-v1` 保持原名，因为用户正是在自己浏览器的工具箱里调出这组数值，本地存储与新默认值一致。若在另一台机器或清过数据的浏览器打开工具箱，会直接读到新的源码默认值。

本轮之前曾读取到用户手机首屏最低高度 796px。它是本地预览值，不是对网站首屏高度的确认，不能擅自固定到网站。修改工具箱并不自动写入 Git 默认配置；确认后才修改上述配置文件。
