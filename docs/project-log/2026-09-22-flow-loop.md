# 2026-09-22 · 流光改为全程循环，时长改为 23 秒

承接 [2026-09-12 至 09-22 时间线](2026-09-12-to-22.md) 第 45 条，本条**替代**其中“流光只覆盖旋转前/旋转/旋转后三阶段”的方案。

## 用户需求

用户给出本地工具箱截图并说明：流光“就不停地在循环，不停地循环”，“没有说到了哪个状态再开始有流光”，因此只需要保留速度这一个可调项。同时要求把截图上的时长和强度写入源码默认值，并明确“仅做这些修改，不要修改这个 hero 动画的什么其他参数”。

## 参数：旧值 → 新值

| 项目 | 旧值 | 新值 |
| --- | --- | --- |
| 白场停留 | 0s | 0s（未改） |
| 白场 → X | 5s | **10s** |
| 旋转前停留 | 0s | **2s** |
| 旋转 180° | 4s | 4s（未改） |
| 旋转后停留 | 1s | **2s** |
| X → 白场 | 5s | 5s（未改） |
| 合计 | 15s | **23s** |
| 流光强度 | 1.5（150%） | **2.9（290%）** |
| 流光速度 | 1.00× | 1.00×（未改） |
| 流光运行区间 | 形成结束 → 退场开始 | **全程，无阶段门控** |
| 流光淡入 `fadeDuration` | 0.45s | **删除** |
| 流光退场刹车 `slowdownDuration` | 0.6s | **删除** |

X 高度 390/650px、2876:1580 比例、噪点 12%/0.9px、宽柔光 8s 周期、弧边细高光 5s 周期、旋转角度与缓动曲线一律未改。

## 实施结果

- [src/config/hero-light.ts](../../src/config/hero-light.ts)：`heroLightTiming` 与 `heroLightFlow` 改为上表新值；`heroFrame` 删除阶段门控、淡入和刹车积分，改为 `flowTime = elapsed`（未取模的累计播放时间）、`flowAmount = 1`。减弱动态模式仍把两者置 0。
- [src/scripts/hero-light.ts](../../src/scripts/hero-light.ts)：仅更新着色器注释，说明流光不再停止、只被退场白场覆盖；uniform 传参方式不变。
- [src/pages/\[preview\].astro](../../src/pages/[preview].astro)：工具箱“持续流光”说明改为“流光不分阶段，全程不停循环”，删去原“退场沿用最后一帧光影”的描述。滑块范围未动（强度 0–300%、速度 0.25–3×）。

用 `elapsed` 而不是取模后的 `time`，是为了让动画循环回到 t=0 时流光相位不跳变——23 秒既不是 8 秒也不是 5 秒的整数倍，用 `time` 会在每轮接缝处看到光突然移位。
