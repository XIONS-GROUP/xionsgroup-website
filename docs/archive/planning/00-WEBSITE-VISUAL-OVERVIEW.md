## 🎬 关键动画效果示意

### 1. Hero 进入动画

```
时间轴：
0.0s  ─────  页面加载
              │
0.2s  ─────  导航栏淡入
              │
0.5s  ─────  Hero标题从下方淡入上升
              │         ↑ translateY(-50px → 0)
              │         ↑ opacity(0 → 1)
1.0s  ─────  CTA按钮淡入
              │         ↑ opacity(0 → 1)
1.5s  ─────  滚动提示开始浮动
              │         ↕ translateY(0 → 10px) 循环

用户体验：优雅、不突兀、引导注意力从上到下
```

### 2. 品牌卡片悬停

```
初始状态：
┌──────────────────┐
│   [图片]         │  border: 1px transparent
│                  │  transform: translateY(0)
│   品牌名称       │  box-shadow: none
└──────────────────┘

      ↓ 鼠标悬停 (0.4s ease)

悬停状态：
┌──────────────────┐
│   [图片放大]     │  border: 1px #D4AF37
│                  │  transform: translateY(-8px)
│   品牌名称       │  box-shadow: 0 16px 32px rgba(0,0,0,0.3)
│   [链接→金色]    │
└──────────────────┘

同时：图片内部 scale(1.05)
```

### 3. 数字滚动计数

```
进入视口时触发：

  0  →  4      (2s ease-out)
  0  →  3      (2s ease-out)
  0  →  20+    (2s ease-out)
  2020 → 2026  (2s ease-out)

使用 CountUp.js 或 GSAP
创造"统计数据实时生成"的效果
```

### 4. 滚动触发淡入

```
元素初始状态（不在视口）：
  opacity: 0
  transform: translateY(40px)

      ↓ 滚动到视口内 (Intersection Observer)

动画：
  opacity: 0 → 1
  transform: translateY(40px → 0)
  duration: 0.8s ease-out

依次触发：
  品牌卡片1 → 延迟0ms
  品牌卡片2 → 延迟100ms
  品牌卡片3 → 延迟200ms
  品牌卡片4 → 延迟300ms

创造"级联"效果
```

## 🔍 SEO & 性能优化概览

### 首屏加载优化

```
关键路径：
1. HTML (内联关键CSS)      ← 10KB
2. Logo SVG (内联)          ← 2KB
3. Hero 背景图 (WebP)       ← 150KB
4. 字体 (仅字重300/400/600) ← 60KB
   ─────────────────────────────────
   总计首屏：~220KB

延迟加载：
- 非关键CSS (异步)
- JavaScript (defer)
- 下方图片 (loading="lazy")
- 动画库 (动态导入)

目标：
- LCP (Largest Contentful Paint) < 2.5s
- FID (First Input Delay) < 100ms
- CLS (Cumulative Layout Shift) < 0.1
```

### 图片优化策略

```
Hero 背景图：
  desktop: hero-2560w.webp (500KB)
  tablet:  hero-1536w.webp (250KB)
  mobile:  hero-828w.webp  (100KB)

品牌卡片图：
  2x: brand-1200w.webp (150KB)
  1x: brand-600w.webp  (60KB)

活动照片：
  全部 loading="lazy"
  全部 WebP + JPG fallback
  全部 responsive sizes

总优化：
  原始：~15MB 图片
  优化后：~2MB 图片（首屏 ~500KB）
  节省：87%
```
