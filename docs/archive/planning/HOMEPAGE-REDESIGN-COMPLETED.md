## 🎨 摆脱AI感的设计细节

### 1. 字体更有个性
```css
✓ Inter 350 weight（不是标准300）
✓ Inter 420 weight（不是标准400）
✓ 创造微妙差异
```

### 2. 颜色不纯黑纯白
```css
✓ 温黑 #0F0F0F（稍偏暖）
✓ 冷白 #FCFCFC（不是纯白）
✓ 金色 #C9A961（柔和版）
```

### 3. 间距有节奏
```
✓ Hero → 品牌：100px
✓ 品牌 → 集团：140px
✓ 集团 → 成果：100px
✓ 成果 → 承诺：140px
✓ 承诺 → 动态：100px
✓ 动态 → CTA：160px
（非机械重复）
```

### 4. 自定义动画缓动
```css
✓ cubic-bezier(0.16, 1, 0.3, 1)
✓ 不用标准的 ease-out
✓ 更流畅自然的动画
```

### 5. 打破对称
```
✓ Hero 文字偏左（不居中）
✓ 品牌网格不等宽（38/62）
✓ 图片不完美居中
✓ 创造视觉张力
```
