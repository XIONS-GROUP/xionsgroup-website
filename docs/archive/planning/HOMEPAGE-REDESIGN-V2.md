## 🎨 摆脱 AI 感的设计细节

### 1. 字体组合更有个性

```css
/* 不要用太常见的组合 */
❌ Inter + Cormorant Garamond （太普通）

/* 试试这些 */
✅ ABC Monument Grotesk + Canela (高端)
✅ Suisse Int'l + Domaine Display (现代)
✅ Graphik + Tiempos (专业)

/* 或保持 Inter，但调整细节 */
✅ Inter Variable（可变字重）
   - 标题用 350 weight（不是 300）
   - 正文用 420 weight（不是 400）
   - 创造微妙差异
```

### 2. 颜色不要纯黑纯白

```css
/* AI 套路 */
❌ 纯黑 #000000
❌ 纯白 #FFFFFF

/* 顶级设计 */
✅ 温黑 #0F0F0F (稍微偏暖)
✅ 冷白 #FCFCFC (不是纯白)
✅ 深灰 #1A1A1A (有层次)
✅ 金色 #D4AF37 → #C9A961 (柔和版)
```

### 3. 间距不要太均匀

```css
/* AI 套路：均匀间距 */
❌ section { margin: 120px 0; }

/* 顶级设计：有节奏 */
✅ Hero → 品牌：100px
✅ 品牌 → 集团：140px
✅ 集团 → 成果：80px
✅ 成果 → 承诺：140px
✅ 承诺 → 动态：100px
✅ 动态 → CTA：160px

创造呼吸节奏，而非机械重复
```

### 4. 动画要定制，不要套路

```javascript
/* AI 套路：fadeInUp */
❌ animation: fadeInUp 1s ease

/* 顶级设计：定制缓动 */
✅ animation: customAppear 1.2s cubic-bezier(0.16, 1, 0.3, 1)

/* 自定义缓动曲线 */
const customEasing = {
  smooth: 'cubic-bezier(0.16, 1, 0.3, 1)',
  bounce: 'cubic-bezier(0.68, -0.55, 0.265, 1.55)',
  elastic: 'cubic-bezier(0.68, -0.75, 0.265, 1.75)',
}

/* Stagger 不要线性 */
❌ delay: 0.1s, 0.2s, 0.3s, 0.4s

✅ delay: 0.1s, 0.15s, 0.25s, 0.45s
   (间隔逐渐增大，更自然)
```

### 5. 打破对称和网格

```css
/* AI 套路：居中对齐 */
❌ text-align: center; margin: 0 auto;

/* 顶级设计：偏移 */
✅ Hero 文字偏左，留右侧呼吸空间
✅ 品牌卡片错位排列
✅ 图片不要完美居中，稍微偏移

/* 网格不要太规则 */
❌ grid-template-columns: 1fr 1fr; (50/50)

✅ grid-template-columns: 38fr 62fr; (黄金比例)
✅ grid-template-columns: 45fr 55fr; (微妙不对称)
```

## 📸 所需素材清单

### 高优先级（首页必需）

1. **Hero 背景**
   - 香水瓶特写 OR 光线穿透液体 OR 产品细节
   - 2560x1440px, WebP
   - 高质量，适合黑白处理

2. **三位创始人合照**
   - 专业摄影，黑白或彩色
   - 至少 1200x800px
   - 表现团队氛围

3. **品牌代表图（4张）**
   - L'Entropiste: 香水瓶
   - Sunlution: 产品+阳光
   - Masqly: 产品使用
   - Betenoir: 神秘氛围图

4. **代表成果照片**
   - 奖项现场或活动照片
   - 2-3张，真实照片
   - 带有可识别的活动标志

### 中优先级（可暂用占位）

5. **最新动态（2-3条）**
   - 活动照片
   - 产品图
   - 新闻配图

6. **承诺相关图片（可选）**
   - 工作场景
   - 产品细节
   - 或纯图标
