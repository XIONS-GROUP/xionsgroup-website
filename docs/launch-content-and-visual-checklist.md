## 上线前优先完成

1. **品牌事实**：确认 Betenoir 公开日期、L’Entropiste 奖项名称与资料、Sunlution / Masqly 功效与研究表述。
2. **集团时间口径**：原文写集团成立于2026；公司注册资料为2022。分别说明法律主体成立与集团/品牌项目启动时间，不能混写。
3. **Press 真实性**：当前六张图仍用 placeholder 文件；“Présence officielle”“défilés majeurs”“partenariats”等具体关系比原文更强，需要真实活动信息。缺素材时隐藏相应卡片。Fashion Week 是网站增补，原文图库列 Golden Globes；应以实际资料决定。
4. **活动标识**：当前 awards SVG 为绘制的简化占位标识，不是已批准的官方资产。换成可用文件或采用普通文字活动名称，明确参与方式，避免暗示官方合作。
5. **视觉落地**：四个品牌 Logo 配置全部为 null；首页轮播列表为空；品牌内页为纯色首屏且尚无图片插槽。集团三人照片、原文要求的产品/奖项图和各类传播图库未完成。
6. **Contact 实测**：已有 Netlify 表单代码，但本轮未验证线上表单启用、提交成功、通知抵达 contact@xionsgroup.com、垃圾信息过滤。Press 的 ?type=press 目前没有自动选择表单主题。
7. **移动端与无障碍**：最终素材入库后检查裁切、文字对比、导航键盘操作、轮播点击区域、暂停与减少动态效果偏好。现有轮播尚无暂停按钮；当前图片叠层与控制条的层级也需要联调。
8. **搜索与分享**：已有 title/description；布局尚无 canonical、Open Graph 分享图与 Apple touch icon。上线时只将 production 的 ALLOW_INDEXING 改为 true（目前 production 仍 false）；dev 继续 noindex。补 sitemap，并检查 / 与 /fr/ 首页重复地址。
9. **招聘与法律**：无明确岗位时保留自荐入口即可。四个法律页面已经存在；最终核对其保存期限、接收方与真实运营流程一致。
10. **发布**：验收 dev → 合并 main → 检查正式域名 HTTPS、首页、404、Contact、社交链接和缓存更新。上述为待验收事项，不表示本轮已验证线上服务。

## 设计收尾方向

首页保留一个视觉重点与四品牌入口；品牌页用“主视觉 → 简介 → 一组产品/证据 → 品牌官网入口”，替换现在重复的三条原则与大号重复标语。先确认各品牌正式官网URL再加入链接。保持共享模板，但允许 Betenoir 采用更短的预告版。无需每页增加图片，否则会重新变成长页面。
