## 🎬 四类动效系统

### 1. 首屏文字出现（Hero）

```javascript
// 逐字淡入（使用 SplitType）
动画时序：
0.0s  ━━━  页面加载
0.3s  ━━━  "IMAGINER" 逐字淡入（每字间隔 30ms）
0.8s  ━━━  "LA BEAUTÉ" 逐字淡入
1.3s  ━━━  "DE DEMAIN" 逐字淡入
1.8s  ━━━  分隔线淡入
2.0s  ━━━  计数器淡入

持续时间：短暂（2s完成）
效果：优雅、不拖沓
移动端：简化为整行淡入（减少性能消耗）
```

### 2. 图片轻微揭示

```css
/* 品牌卡片 */
.brand-card {
  overflow: hidden;
}

.brand-card img {
  transform: scale(1.1);
  transition: transform 0.8s cubic-bezier(0.4, 0, 0.2, 1);
}

/* 滚动进入视口时 */
.brand-card.in-view img {
  transform: scale(1);
}

/* 悬停时 */
.brand-card:hover img {
  transform: scale(1.05);
}

效果：
- 初始：图片稍大，遮挡部分
- 进入：缓慢缩回到正常
- 悬停：轻微放大
- 时间：0.8s（足够优雅）
```

### 3. 品牌卡片反馈

```css
.brand-card {
  transition: all 0.25s ease-out;
}

.brand-card:hover {
  transform: translateY(-8px);
  box-shadow: 0 16px 48px rgba(0, 0, 0, 0.12);
}

.brand-card::after {
  content: '';
  position: absolute;
  inset: 0;
  border: 1px solid transparent;
  transition: border-color 0.25s ease;
}

.brand-card:hover::after {
  border-color: rgba(201, 169, 97, 0.3); /* 淡金色 */
}

效果：
- 快速响应（250ms）
- 轻微上浮
- 金色边框淡入
- 阴影加深
```

## 📱 移动端优化方案

### 字体大小调整

```css
/* 当前问题：移动端字体太大 */
当前：
h1: 96px → 移动 52px（仍然偏大）

改进：
/* 桌面端 */
@media (min-width: 1024px) {
  h1 { font-size: 96px; }
  h2 { font-size: 64px; }
  h3 { font-size: 48px; }
  p  { font-size: 18px; }
}

/* 平板端 */
@media (min-width: 768px) and (max-width: 1023px) {
  h1 { font-size: 64px; }
  h2 { font-size: 48px; }
  h3 { font-size: 36px; }
  p  { font-size: 16px; }
}

/* 移动端（大屏手机）*/
@media (min-width: 481px) and (max-width: 767px) {
  h1 { font-size: 42px; }
  h2 { font-size: 36px; }
  h3 { font-size: 28px; }
  p  { font-size: 15px; }
}

/* 移动端（小屏手机）*/
@media (max-width: 480px) {
  h1 { font-size: 36px; }  /* 大幅缩小 */
  h2 { font-size: 32px; }
  h3 { font-size: 24px; }
  p  { font-size: 15px; }
  
  /* 行高也要调整 */
  h1 { line-height: 1.1; }
  p  { line-height: 1.6; }
}
```

### 布局适配

```css
/* 品牌展示区域 */
当前问题：全屏滚动在移动端不自然

改进：
/* 桌面：2x2 网格 */
@media (min-width: 1024px) {
  .brands-grid {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 2px; /* 极细分隔 */
  }
}

/* 移动：单栏堆叠 */
@media (max-width: 767px) {
  .brands-grid {
    display: flex;
    flex-direction: column;
    gap: 0;
  }
  
  .brand-card {
    height: 70vh; /* 不是 100vh，留出滚动空间 */
  }
}
```

### 触摸优化

```css
/* 移动端增大点击目标 */
@media (max-width: 767px) {
  .btn, .link {
    min-height: 44px; /* Apple 建议的最小触摸目标 */
    padding: 12px 32px;
  }
  
  .nav-link {
    padding: 16px 0;
  }
}
```

## 💡 设计哲学总结

```
整体方向：
暖白底 + 近黑文字 + 大幅摄影 + 宽松留白 + 少量艺术运动

品牌个性：
统一框架 + 个性图片 + 局部颜色

动效原则：
少即是多
正常滚动 + 清楚导航
手机简化 + 静态优先
```
